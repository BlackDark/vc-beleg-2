# Go backend with Huma, separate from Spesen

The preset default is TypeScript with TanStack Start. We use Go (stdlib router, Huma for code-first OpenAPI, SQLite with embedded migrations) and a React SPA embedded in the binary, with the client generated by Hey API. The owner prefers Go, and the sibling app Spesen (vc-geschaeftsausgabentest) already proves this stack, its Pocket ID login, receipt handling, Typst export and backup.

Mahlzeit stays a separate app instead of a module in Spesen: a payroll benefit (Sachbezug) and a travel reimbursement are different domains. Spesen code is copied and adapted; shared Go packages may be extracted once both apps are stable.

## Considered Options

- tygo (Go structs → TS types): no generated Zod schemas or Query hooks; more hand-written client code.
- Spec-first with oapi-codegen: a hand-maintained spec for a single-owner app.
