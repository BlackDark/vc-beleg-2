# One allowance per working day, no full-day model

R 8.1 Abs. 7 Nr. 4 LStR and the BMF letter of 18.01.2019 allow one meal allowance per working day. The full-day value (2026: €2.37 + €4.57 + €4.57 = €11.51) belongs to free board provided by the employer (freie Verpflegung), not to receipt-based allowances, so it is not modelled as a tax model. The rate table still stores breakfast, lunch and dinner values per year, so "breakfast instead of lunch" stays cheap if a tax adviser confirms a need.
